## ✦ The idea

Aevora is built around a simple question:

> **What if interacting with the web started with intent, not selectors?**

Traditional automation asks you to describe every step. Aevora is designed to let an AI agent understand a goal, observe a browser, and execute the actions needed to accomplish it.

```text
┌──────────────────────────────────────────────────────────┐
│                                                          │
│   "Research the best options and compare them."         │
│                                                          │
└──────────────────────────┬───────────────────────────────┘
                           ↓
                  ┌─────────────────┐
                  │   AEVORA CORE   │
                  │                 │
                  │  Observe        │
                  │  Reason         │
                  │  Act            │
                  └────────┬────────┘
                           ↓
                  ┌─────────────────┐
                  │  Browser Layer  │
                  └────────┬────────┘
                           ↓
                  ┌─────────────────┐
                  │  The Web        │
                  └─────────────────┘
```

## ◈ What can Aevora do?

Aevora is designed for **goal-oriented browser automation**, where the agent can interact with websites instead of relying entirely on rigid, predefined workflows.

### **01 · Fill forms**

Give the agent a task and let it work through the interface.

```text
"Fill in this application using my information."
```

### **02 · Extract intelligence**

Turn web pages into useful, structured information.

```text
"Collect the relevant data and organize the results."
```

### **03 · Execute workflows**

Move beyond individual clicks and into multi-step browser tasks.

```text
"Research, compare, and return the best options."
```

## ⟡ How it works

Aevora follows an agentic execution loop:

```text
                    ┌──────────────┐
                    │  User Goal   │
                    └──────┬───────┘
                           │
                           ▼
                    ┌──────────────┐
                    │  Understand  │
                    │    Intent    │
                    └──────┬───────┘
                           │
                           ▼
                    ┌──────────────┐
                    │   Observe    │
                    │   Browser    │
                    └──────┬───────┘
                           │
                           ▼
                    ┌──────────────┐
                    │    Reason    │
                    │  Next Action │
                    └──────┬───────┘
                           │
                           ▼
                    ┌──────────────┐
                    │     Act      │
                    │ Click / Type │
                    │ Navigate     │
                    └──────┬───────┘
                           │
                           ▼
                    ┌──────────────┐
                    │    Repeat    │
                    │ Until Done   │
                    └──────────────┘
```

**Intent → Observation → Reasoning → Action → Result**

The browser becomes the execution environment, while the agent handles the decision-making.
